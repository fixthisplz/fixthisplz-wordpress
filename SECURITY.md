# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Report it privately through GitHub: open the [Security tab](https://github.com/fixthisplz/fixthisplz-wordpress/security) of this repository and click **Report a vulnerability** ([direct link](https://github.com/fixthisplz/fixthisplz-wordpress/security/advisories/new)). Only the maintainers can see the report.

Please include the plugin version, the WordPress and PHP versions, the steps to reproduce and the impact you expect. We will acknowledge the report, keep you informed, and credit you in the advisory if you wish.

## Supported versions

Security fixes are made on the latest released version only.
